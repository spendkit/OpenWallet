# Getting help

- **Usage questions and ideas:** open a GitHub Discussion (or an issue if Discussions are off).
- **Bugs:** open an issue with the steps, the expected result and what happened. Remove tokens, keys and card details first.
- **Security problems:** never a public issue; see [SECURITY.md](SECURITY.md).
- **Starting point:** [docs/getting-started.md](docs/getting-started.md) and its troubleshooting table.
